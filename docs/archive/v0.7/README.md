# Archived: the v0.7 introduction deck

This deck (`introduction/` and `OAA-Introduction.pptx`) was written for OAA 0.7. It describes the
`oaa-harness` MCP server and its tools, and treats `CLAUDE.md` as the OAA skill. Both changed in 0.8:
compile and validate now run through the `oaa.mjs` utility, the procedures are prompts, and the
company's `README.md` is the router. The deck is kept for reference and has not been updated.

For how OAA works now, read the repository `README.md` and `skills/org-agent-architecture/SKILL.md`.
