# Slide 8 — The System Prompts

**Title:** The System Prompts
**Tagline:** You author node files. The skill and compilers generate all the prompts.

---

## Key Message

OAA runs on prompts. Every file that an agent reads at runtime is a prompt — authored or compiled. Understanding which is which is critical: two of them are generated on every compile run, and editing them by hand gets overwritten silently.

---

## The Six Prompts

### `CLAUDE.md` — The OAA skill (installed at the company root)
- **This IS the OAA skill** — installed via `npx skills add Chuck3PointZero/OAA`
- Tells any AI assistant working in the tree that everything below follows the OAA convention and how to compile agents
- Not compiled from node files — it is what compiles everything else
- Without it, an assistant has no context for why the files are shaped the way they are

### `AGENTS.md` — Generated (per agent, by `compile_agent`)
- `compile_agent` walks the full AGENT→ROLE→SKILL→TOOL chain and writes one `AGENTS.md` per agent
- Inlines every tool's `never` rules verbatim, the memory schema, run order, escalation dispatch, and the env-var name table
- Stamped: `<!-- GENERATED by compile_agent — do not hand-edit -->`
- **At run time, this file IS the agent's system prompt** — the actual payload handed to the LLM, not a description of the agent
- For `executor: remote` agents, the same file is POSTed to the endpoint

### `mcp-config.json` — Generated (per agent, by `compile_agent`)
- Written alongside `AGENTS.md` on every `compile_agent` run
- Merges the `server/mcp.json` of every tool the agent's chain requires into one config
- Passed to the runner via `--mcp-config` — scopes the run to exactly the tools `AGENTS.md` names
- Not hand-authored; regenerated on every compile

### `ONTOLOGY.md` — Generated (by `compile_ontology`)
- Compiled from `.rel` source files in the `ontology/` directory
- Declares every entity, its properties, and every derived concept with its condition rule
- Injected automatically into `AGENTS.md` by `compile_agent`
- Edit the `.rel` sources, not the compiled file

### `COMPANY.md` — Generated (by OAA skill, via `company-map-system-prompt.md`)
- The plain-English reference that maps every role to its agent, schedule, and authority boundaries
- Generated by the OAA skill reading the full node graph and applying the company-map prompt
- Stamped: `<!-- GENERATED — do not hand-edit -->`
- Audience: non-technical stakeholders who need to understand the org chart without opening node files

### Compact Rewrite Template (`get_compact_prompt_template`)
- When an agent has `models: [tiny]`, `compile_agent` flags `compactNeeded: true` and writes `AGENTS.orig.md` as a full backup
- `get_compact_prompt_template` returns a rewrite prompt that strips rationale and prose from `AGENTS.orig.md` while preserving every tool name, env var, and `never` rule verbatim
- The result is a smaller `AGENTS.md` footprint suitable for small-context models
- `AGENTS.orig.md` is also a generated artifact — not for hand-editing

### `company-map-system-prompt.md` — Authored (in the OAA skill's assets)
- The prompt that instructs an AI to generate `COMPANY.md` from raw node data
- Lives at `skills/org-agent-architecture/assets/prompts/company-map-system-prompt.md`
- Rules: never invent authority items, thresholds, or tool names; never include skill workflow steps; output only the Markdown

## The Prompt Table

| Prompt | Authored / Generated | Produced by | Purpose |
|--------|---------------------|-------------|---------|
| `CLAUDE.md` | Installed (the OAA skill) | `npx skills add` | Entry-point system prompt for the whole repo |
| `AGENTS.md` | Generated (per agent) | `compile_agent` | The agent's runtime system prompt |
| `mcp-config.json` | Generated (per agent) | `compile_agent` | Tool server config for this agent's run |
| `ONTOLOGY.md` | Generated | `compile_ontology` | Compiled domain vocabulary, injected into AGENTS.md |
| `COMPANY.md` | Generated | OAA skill + company-map prompt | Plain-English org map for stakeholders |
| Compact rewrite template | Runtime (on demand) | `get_compact_prompt_template` | Drives Pass 2 rewrite for `models: [tiny]` agents |
| `company-map-system-prompt.md` | Part of the OAA skill | OAA skill assets | Instructs AI to generate COMPANY.md |

## Speaker Notes

- The most common onboarding mistake: opening `AGENTS.md` and editing it directly. The next `compile_agent` call overwrites those edits silently. AGENTS.md is output, not input.
- `CLAUDE.md` is unusual — the only file that is not compiled from a node and not a generated artifact. It bootstraps any AI assistant into the OAA structure of this particular repo.
- `mcp-config.json` is often forgotten — without it, the runner either uses a global config (wrong tools) or no tools at all. `--strict-mcp-config` scopes the run to only what `compile_agent` declared.
- The compact rewrite is Pass 2 in the compile flow. Pass 1 = full `AGENTS.md`. Pass 2 = `get_compact_prompt_template` rewrite → smaller `AGENTS.md`, `AGENTS.orig.md` backup preserved.
- `COMPANY.md` is the one prompt intended for humans, not LLMs. It is how a manager or compliance reviewer understands the org chart without reading source nodes.
